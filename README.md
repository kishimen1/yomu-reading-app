# YOMU - Android読書管理アプリ モックアップ

ビブリアの主要な読書記録体験をAndroid向けに再構成し、分析とデータ可搬性を強化したPWAモックです。実在アプリの名称・画面・素材は複製せず、機能要件だけを参照した独自デザインです。

## すぐ試す

このフォルダーで次を実行します。

```powershell
python -m http.server 8000
```

Android端末とPCが同じネットワークにある場合は、PCのIPアドレスを使って `http://<PCのIP>:8000` をChromeで開きます。Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選ぶと、スタンドアロン表示で利用できます。

PCだけで確認する場合は `http://localhost:8000` を開きます。登録内容はブラウザーの `localStorage` に保存されます。

## モックで操作できること

| 領域 | 実装済み |
| --- | --- |
| 本棚 | 読んだ・読書中・読みたいの切替、グリッド/リスト表示、AND検索、4種類の並び替え |
| 登録 | カメラプレビュー、バーコード読取デモ、書誌検索デモ、手入力 |
| 記録 | タイトル・著者・本棚・読了日・評価・メモ・感想の編集、削除、共有 |
| 分析 | 読了数、ページ数、平均評価、著者数、ジャンル円グラフ、月別推移、評価分布 |
| データ | UTF-8 BOM付きCSV、完全JSONバックアップ、JSON復元 |
| 端末 | ローカル保存、PWAインストール、オフラインキャッシュ、ライト/ダーク表示 |

## モックの境界

- 書誌検索結果とバーコード結果はサンプルデータです。カメラプレビューまでは実機能ですが、ISBNの画像認識は未接続です。
- ログイン、端末間同期、クラウドバックアップ、Dropbox連携はありません。
- 書影は本モック向けに生成した架空書籍用の素材です。実在する書籍データは含みません。
- CSVは分析用の書き出しです。モックへの復元はJSONに限定しています。
- PWAのカメラ利用はHTTPSまたはlocalhostが必要です。LAN内のHTTPではブラウザーによりカメラが制限されます。

## 本稼働版の推奨構成

| レイヤー | 推奨技術 | 目的 |
| --- | --- | --- |
| アプリ | TypeScript + Vite + Capacitor | モックのWeb UIを活かしてAndroidアプリ化 |
| 端末DB | SQLite + マイグレーション | 大量データ、全文検索、確実なオフライン利用 |
| バーコード | Google ML Kit Barcode Scanning | ISBN-10/13の高速・連続スキャン |
| 書誌 | openBD + Google Books APIのフォールバック | 日本語書籍のタイトル、著者、表紙、説明を取得 |
| 同期 | FirebaseまたはSupabase（任意選択） | ログイン利用者だけ暗号化同期・復旧 |
| バックアップ | Google Drive App Data / 端末ファイル | Androidでのバックアップ・復元 |
| 品質 | Vitest + Playwright + Android実機テスト | データ移行、主要導線、画面崩れの回帰防止 |

## 公開までのロードマップ

### 1. 要件確定と試用（1-2週間）

- 10-20人でモックを試し、本棚、登録、詳細、分析の優先順位を確認
- ビブリア互換CSVのインポート要否と列仕様を確定
- ジャンルを自動推定するか、ユーザー編集を正とするか決定
- アプリ名、利用規約、プライバシーポリシー、書誌・書影の利用条件を確定

### 2. Android MVP（4-6週間）

- TypeScript化し、UIをコンポーネント単位へ分割
- SQLiteのデータモデルとバージョン付きマイグレーションを実装
- ML Kitバーコード、書誌API、ネイティブ共有、画像差し替えを接続
- CSV/JSONの往復、ビブリア形式インポート、重複検知を実装
- TalkBack、文字拡大、ダークモード、オフライン動作を実機で検証

### 3. 同期・運用品質（3-5週間）

- 同期を希望するユーザーだけが利用するアカウント機能を追加
- 競合解決、論理削除、復元、暗号化、退会時削除を実装
- Crashlytics等のクラッシュ監視と、個人情報を含めない分析イベントを設計
- 5000冊規模の表示、検索、エクスポート性能を測定

### 4. Google Play公開（2-3週間）

- Play App Signing用AAB、アプリアイコン、スクリーンショット、ストア説明を準備
- Data safety、コンテンツレーティング、広告有無、アカウント削除導線を申告
- 内部テストからクローズドテストへ進み、端末別クラッシュとANRを確認
- 段階公開し、DB移行成功率・クラッシュ率・登録完了率を監視

## 本稼働前の受け入れ基準

- 機内モードでも既存記録の閲覧・編集・分析ができる
- アプリ更新後も全記録、メモ、評価、書影リンクが欠損しない
- CSVをExcel、Power BI、Tableauで文字化けなく読み込める
- バーコードから本棚登録まで、通常3タップ以内で完了する
- TalkBackの読み上げ順と、200%文字拡大時の主要操作を保証する
- 削除、復元、同期競合、端末変更のテストケースが自動化されている
